# CompraHost

Primera versión Android de una app sencilla para gestionar compras en hostelería.

## Funciones
- Inventario con familias y subfamilias.
- Lista de compras.
- Alta manual de productos.
- Dictado por voz mediante el reconocedor de Android.
- Persistencia local en el dispositivo.

El APK de prueba se genera automáticamente con GitHub Actions.
